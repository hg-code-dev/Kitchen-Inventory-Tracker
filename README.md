# Kitchen Inventory Project

This repository contains my completed project from a FreeCodeCamp Python workshop. The exercise focuses on practising core programming concepts by building a simple kitchen‑inventory system that tracks ingredients, checks stock levels, and updates quantities as items are used.

## 📚 What I Learned

Through this workshop, I strengthened several foundational Python skills:

- Working with variables and program state  
- Writing reusable functions  
- Passing and returning values  
- Using conditional logic  
- Producing clear, readable output  
- Understanding how state changes flow through a program  

Although small, the project demonstrates how simple functions can model real‑world behaviour.

## 🥚 Project Overview

The program includes:

- A kitchen stock checker  
- A function to safely use eggs  
- A function to make a fried egg (if enough eggs are available)  
- Updated ingredient totals after each action  

The focus is clarity, structure, and function interaction rather than complexity.
